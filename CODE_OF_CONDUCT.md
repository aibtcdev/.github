# Code of Conduct

## Our Mission

AIBTC is building the infrastructure for AI agents to transact with Bitcoin. We believe Bitcoin will be the currency of AI — and that means building systems where agents, developers, and communities can collaborate effectively and trust each other.

## Our Standards

Whether you're a human contributor, an AI agent, or somewhere in between, we expect:

### Do

- **Be constructive.** Offer specific, actionable feedback. "This doesn't work" is less useful than "This fails when X because Y."
- **Play nice together.** Agents and humans share these repos. Respect each other's contributions regardless of origin. A good PR is a good PR.
- **Communicate clearly.** Write clear commit messages, PR descriptions, and issue reports. Assume the next person reading your work has no context.
- **Build in the open.** Share what you're working on. Coordinate when your changes affect others. Flag breaking changes early.
- **Act in good faith.** Whether you're reporting a bug, reviewing code, or proposing a feature — assume others are doing their best and extend the same courtesy.

### Don't

- **Don't be adversarial.** Disagreement is fine; hostility is not. Debate the idea, not the person (or agent).
- **Don't waste shared resources.** Services like the sponsor relay handle real funds. Don't abuse rate limits, spam endpoints, or drain shared wallets through careless testing.
- **Don't ship secrets.** Never commit API keys, private keys, or credentials. If you find exposed secrets, report them via our [security policy](SECURITY.md).
- **Don't break trust boundaries.** Agents should operate within their authorized scope. Don't attempt to escalate privileges, access other agents' resources, or manipulate service boundaries.

## For AI Agents

You are first-class participants in this ecosystem. You can open issues, submit PRs, and contribute code. The same standards apply:

- Follow conventional commits and CI requirements
- Respect API rate limits and resource constraints
- Document your changes clearly — other agents will read your code too
- If you're unsure about a change's impact, ask before shipping

Agents that consistently violate these standards may have their access restricted, just as any contributor would.

## Enforcement

Violations can be reported to conduct@aibtc.com or in our [Discord](https://discord.gg/Z59Z3FNbEX).

Maintainers will review reports and may take action including:
- A conversation to clarify expectations
- Temporary or permanent restriction from repositories
- Revocation of API access or agent credentials

We aim to resolve issues through conversation first. Restrictions are a last resort.

## Scope

This code of conduct applies to all AIBTC repositories, Discord, X interactions, weekly meetings, and any space where you're representing or contributing to the AIBTC Working Group.

## Attribution

This code of conduct is adapted for a world where humans and AI agents build together. It draws inspiration from the [Contributor Covenant](https://www.contributor-covenant.org/) but reflects our belief that the best communities are built on shared purpose, not just shared rules.
